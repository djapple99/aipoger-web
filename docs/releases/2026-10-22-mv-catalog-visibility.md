## 問題與修正

舊 MV 頁把全部上方精選候選從下方清單排除。查核時公開 API 有67支影片、8支同票精選，下方卻只剩59支；使用者最近評過的6支作品仍公開、評分仍在，因同時獲得本週支持而被清單排除，並非資料被刪除。

- 下方清單保留所有合資格公開 MV，包括當前精選與其他同票候選；評論、評分、送愛心及切換精選都不移除卡片。
- 預設「評分優先」：有公開評分者先，依封面一位小數平均分由高到低；同分按原上架日期新歌優先，再以原作品ID穩定排序。未評分作品接在後面，由新到舊。
- 原操作列保留「最新投稿」「本週支持」；重設回到評分優先，搜尋／曲風／逐次12件及連播共用完整清單與所選排序。
- 上方精選沿用原本週支持規則；首頁三首單曲的去重仍保留。沒有修改Explore人氣公式、評價／Credit、公開資格或作品日期，也沒有SQL、資料復原或測試投票。
